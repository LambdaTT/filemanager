💬 Commentaries:

Housekeeping pass aligning this module's plumbing with the IAM permissions-domain simplification
(IAM v1.3.0). No change to who can access the endpoints.

---

🔧 Changed:

    ▸ Module presence is now checked via `ModsManager::modExists('iam')` instead of the
      `modcontrol/control` service, and the auth guard is wired to the tag-based
      `iam/permission->requireAny()` helper.

    ▸ Removed the disabled `validatePermissions()` reference and its TODO. The import endpoints
      remain authentication-only — they enforce a valid session but no entity-level permission.
